# 🧮 Calculator Project Using Python

A simple **Calculator Project using Python** that performs basic arithmetic operations such as **addition, subtraction, multiplication, and division**.

This project is created as a beginner-level Python project to practice **variables, user input, conditional statements, and exception handling**.

## 📌 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- ⚠️ Handles division by zero
- ❌ Displays a message for invalid operations
- 🔢 Accepts decimal numbers using `float()`

## 🛠️ Technologies Used

- **Python 3**
- `input()`
- `float()`
- `if-elif-else`
- `try-except`
- f-strings

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/python-calculator.git
```

### 2. Open the project folder

```bash
cd python-calculator
```

### 3. Run the Python program

```bash
python calculator.py
```
